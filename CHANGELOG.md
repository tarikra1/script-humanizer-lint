# Changelog

All notable changes to `script-humanizer-lint` are documented in this file.

## [1.0.0] - 2026-11-25

### Added
- Rule engine catching staged AI run-ups (`Let's dive in`, `Here's the thing`), `Not X, but Y` contrast clichés, em-dash (`—`) punctuation, and stock AI buzzwords.
- Spoken breath-length checker flagging sentences above configurable word limits (default `22` words) for crisp voiceover delivery.
- CLI (`script-humanizer`) and GitHub Actions CI matrix.
